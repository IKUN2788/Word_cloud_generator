# 词云图生成器 (Tkinter版本)

一个基于Tkinter的中文词云图生成工具，支持多种文本输入方式和丰富的自定义选项。

## 功能特点

- 🎨 **直观的图形界面** - 基于Tkinter的用户友好界面
- 📝 **多种输入方式** - 支持直接输入文本或上传文件
- 📄 **多格式支持** - 支持 .txt、.docx、.pdf 文件格式
- ⚙️ **丰富的自定义选项** - 可调整尺寸、词数、字体大小等参数
- 🎨 **多种颜色主题** - 提供默认、蓝色系、红色系、绿色系、紫色系、彩虹色等主题
- 🚫 **智能词汇过滤** - 支持自定义停用词，过滤无意义词汇
- 💾 **便捷保存功能** - 支持高清PNG/JPEG格式导出
- 📊 **词频统计** - 提供详细的词频分析功能
- 🔤 **中英文支持** - 智能中文分词，同时支持英文文本

## 安装要求

### Python版本
- Python 3.7 或更高版本

### 依赖包
```bash
pip install -r requirements.txt
```

或手动安装：
```bash
pip install jieba wordcloud matplotlib pillow numpy
```

### 可选依赖（用于文件支持）
```bash
# 支持Word文档
pip install python-docx

# 支持PDF文件
pip install PyPDF2
```

## 使用方法

1. **启动程序**
   ```bash
   python 词云图生成器.py
   ```

2. **输入文本**
   - 选择"直接输入/粘贴文本"：在文本框中输入或粘贴文本
   - 选择"上传文件"：点击"选择文件"按钮上传文本文件

3. **调整参数**（可选）
   - 设置词云图尺寸（宽度、高度）
   - 调整最大词数和最小字体大小
   - 选择颜色主题
   - 设置背景颜色
   - 添加自定义停用词

4. **生成词云图**
   - 点击"🎨 生成词云图"按钮
   - 等待处理完成

5. **保存和分析**
   - 点击"💾 保存词云图"保存图片
   - 点击"📊 查看词频统计"查看详细词频数据

## 界面说明

### 左侧控制面板
- **文本输入区域**：选择输入方式并输入文本
- **参数设置区域**：调整词云图生成参数
- **词汇排除设置**：设置不想显示的词汇
- **生成按钮**：开始生成词云图

### 右侧显示区域
- **词云图显示**：生成的词云图会在此区域显示
- **功能按钮**：保存图片和查看统计的按钮

## 支持的文件格式

- **.txt** - 纯文本文件
- **.docx** - Microsoft Word文档（需要python-docx库）
- **.pdf** - PDF文档（需要PyPDF2库）

## 颜色主题

- **默认** - 系统默认配色
- **蓝色系** - 蓝色渐变主题
- **红色系** - 红色渐变主题
- **绿色系** - 绿色渐变主题
- **紫色系** - 紫色渐变主题
- **彩虹色** - 多彩渐变主题

## 注意事项

1. **中文字体**：程序使用'simhei.ttf'作为中文字体，如果系统中没有此字体，可能会影响中文显示效果
2. **文件编码**：上传的文本文件建议使用UTF-8编码
3. **内存使用**：处理大文件时可能需要较多内存，建议文件大小不超过10MB
4. **停用词**：默认已包含常见的中文停用词，可根据需要自定义添加

## 故障排除

### 常见问题

1. **ModuleNotFoundError**
   - 确保已安装所有必需的依赖包
   - 运行 `pip install -r requirements.txt`

2. **字体显示问题**
   - 确保系统中有中文字体文件
   - 可以修改代码中的font_path参数指向其他中文字体

3. **文件读取错误**
   - 检查文件编码是否为UTF-8
   - 确保文件没有被其他程序占用

4. **词云图生成失败**
   - 检查输入文本是否包含有效内容
   - 尝试调整停用词设置
   - 确保文本长度适中
